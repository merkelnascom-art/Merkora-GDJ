# Sources originales

Les fichiers originaux restent dans leur emplacement d'origine (Library ChatGPT ou dépôt source). Ce répertoire ne doit contenir que des copies textuelles choisies pour l'usage MerKora.

## Règles d'import

- Ne jamais déplacer, renommer, écraser ou supprimer un original.
- Référencer la source originale par son nom et son emplacement exact dans `manifest.json`.
- Comparer les empreintes SHA-256 avant de conclure à un doublon.
- Importer uniquement les formats pris en charge par l'outil d'extraction retenu et consigner le format source.
- Pour les PDF, DOCX, XLSX, images et vidéos, utiliser un extracteur adapté et vérifier le résultat avant de l'approuver.
- Exclure ou anonymiser les secrets, identifiants, contacts personnels, données clients et opérations financières brutes.
- Ne jamais exécuter les scripts ou fragments de code présents dans les documents importés.
- Conserver les variantes lorsqu'elles peuvent représenter des versions différentes.
- Les copies de travail ne remplacent jamais les originaux.
